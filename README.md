MY OS — Web Desktop Environment

MY OS is a custom web-based desktop environment built to act like a desktop operating system.

Features

• Interactive UI: A dark-themed layout laid over a starry-night background.  

• Draggable Windows: Floating windows (like the Welcome box) can be dragged, closed, and repositioned across the space.  

• Live System Metrics: A top bar displaying the project name, quote, and a live clock.  

• Notes Application: A text editor app where you can write notes for each day and/or save, delete or create a new note.  

• Fortfact App: A fun app designed to give random facts or fortunes.   

 NEW:
  
• Widgets:     
        • Stopwatch: A working stopwatch that counts minutes, seconds, and milliseconds. It can be paused and reset as well.    
        •  Event Countdown: You can set a date and time and it counts down from now how many days, hours, minutes, and seconds left.

•  Calculator App: A calculator that can solve equations.

• Wallpaper Customization: You can change the background to one of the 3 options given. It is in the widget panel. It uses local storage to save onto your computer the background you chose.

• UPDATES to the Notes App:     
        • Persistence: Your notes now save onto your device so when you come back later you can continue where you left off.      
        • Customization: Now when you add a new note it will ask you what you want the title will be and it will use that as the title.
